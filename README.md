# Template — Nest API

GitHub **template repository** for new NestJS + Prisma services under [Khaled-Abdelbaset](https://github.com/Khaled-Abdelbaset).

## Use this template

1. GitHub → **Use this template** → create `your-api`.
2. Clone: `git@github.com-khaled-abdelbaset:Khaled-Abdelbaset/your-api.git`
3. Set git email: [GIT_IDENTITY.md](https://github.com/Khaled-Abdelbaset/engineering-standards/blob/main/docs/GIT_IDENTITY.md)
4. `cp .env.example .env`, `npm ci`, `npm run dev`

## Workflow

See [CONTRIBUTING.md](CONTRIBUTING.md) and [engineering-standards](https://github.com/Khaled-Abdelbaset/engineering-standards).
